# 02 角色

## 关系网

- 麦生 ↔ 父亲李长顺：信条的传递者与负债者。“读到哪儿，爹供到哪儿”既是爱，也是绳索。
- 麦生 ↔ 母亲王秀兰：最柔软的牵挂，也是最日常的催逼。“啥时候结婚”与“钱够不够”是同一句话的两面。
- 麦生 ↔ 姐姐李麦香：他脚下踩着的，是姐姐没走成的那条路。她从不讨债，这笔债才最重。
- 麦生 ↔ 何静：九年异地，等成一个“看不到头”。她不是变心，是等不起了。
- 麦生 ↔ 陈立群（硕导）：唯一真正相信他“是块料”的人，也是唯一无力救他的人。
- 麦生 ↔ 周世昌（博导）：不是恶人，是另一套考核体系里的幸存者。他欣赏麦生的韧，也消耗他的韧。
- 麦生 ↔ 张弛（同门）：同一条跑道上的两种起点。张弛不是对手，是镜子。
- 麦生 ↔ 李强（发小）：初中毕业，开装修公司，房车二胎。他的客气，比嘲讽更伤人。
- 麦生 ↔ 一穗麦子：从家里带来的，放在书包夹层、工位信封、夹克口袋。最后回到家里。

## 角色：李麦生（主人公）

- **出生**：1988 年芒种前后，豫南李湾村。取名“麦生”，因为生在麦收。
- **外貌**：瘦，肩窄，戴一副黑框眼镜；手指细长，指甲剪得很短；三十岁后鬓角早白；夹克洗得发白。
- **欲望（表层）**：读完博士，进高校，当老师，把父母接出村子。
- **需求（深层）**：被承认“我这个人算数”——不是“李湾村第一个博士”算数，是他自己算数。
- **缺陷**：把学历当成唯一的尊严来源；不肯低头、不肯回县城、不肯让村人看笑话；对家人报喜不报忧，撒谎成了习惯。
- **秘密**：他其实羡慕李强；他其实想过退学；他在博后第一年就动过死的念头，但没敢。
- **弧光**：相信“读书改命”→ 发现命改了、人没处落 → 在“回县城”与“再撑一年”之间反复 → 最终选择从实验楼天台跳下。他至死没有恨过任何人，只恨自己“没用”。
- **语言指纹**：对家人永远说“挺好”“不缺钱”“再等一年”；对导师说“中”“我知道了”；对何静说得最多的是“再给我一点时间”。句式短，少用形容词。
- **与主线的关系**：唯一主视角。全书的每一个制度细节，都从他的眼睛里过。

## 角色：李长顺（父亲）

- **身份**：1962 年生，农民，初中文化，会开手扶拖拉机，会扬场，会看麦子的成色。
- **外貌**：黑、瘦，背微驼；右手食指缺半截（年轻时被脱粒机咬的）；手掌像树皮，裂口用白胶布缠。
- **欲望**：供出一个读书人，让李家“改门风”。
- **缺陷**：沉默、要强、不会表达；把爱换算成钱和粮食；病了也瞒着，怕花钱。
- **秘密**：他其实知道麦生在城里过得不好。他不问，是怕问出来，自己帮不上。
- **弧光**：从“读到哪儿供到哪儿” → 到病中仍说“别耽误学业” → 到葬礼上把一墙奖状一张张烧掉，只留最早的一张。
- **语言指纹**：短句，命令式，“中”“别省”“回来吧”“不碍事”。从不说“我爱你”，只说“钱够不够”。

## 角色：王秀兰（母亲）

- **身份**：1964 年生，识字不多，会写自己的名字和“麦生”两个字。
- **外貌**：矮胖，头发花白，走路外八字；手上有洗不掉的泥和草汁。
- **欲望**：儿子成家、抱孙子；一家人在村里“抬得起头”。
- **缺陷**：唠叨、迷信、爱面子；对外说儿子在“南方大学教书”，说着说着自己都信了。
- **秘密**：她偷偷去镇上问过“抑郁症是啥病”，医生说了半天，她只记住一句“想开点”。
- **弧光**：从催婚、催工作 → 到儿子死后，把博士服叠好放进棺材 → 到一年后，把地流转出去，只留坟边两分地。
- **语言指纹**：“吃了吗”“钱够不够”“啥时候回来”“别熬夜”“妈不催你”。

## 角色：李麦香（姐姐）

- **身份**：1985 年生，初中毕业，十六岁去东莞电子厂，后到郑州服装厂、超市理货；三十岁嫁到邻村，丈夫跑货车，有一个儿子小宝。
- **外貌**：比实际年龄显老；手粗，指甲修得整齐；耳朵上戴一对很小的金耳环，是结婚时买的，平时不戴。
- **欲望**：弟弟有出息；自己的儿子别再走她的路。
- **缺陷**：把牺牲当成理所当然，从不诉苦；越不诉苦，弟弟越不敢面对她。
- **秘密**：她当年也想读书，成绩不差。她烧过自己的录取通知书？不——她没考上高中，差十二分。这个细节更疼。
- **弧光**：从“你只管读，钱我出” → 到父亲病时拿出三万 → 到弟弟死后，在他手机里听到那条没发出去的语音。
- **语言指纹**：“中”“你别管”“我有”“你吃胖了”“妈，你别哭了”。

## 角色：何静（女友）

- **身份**：1989 年生，县城姑娘，父母是小学教师/供销社职工；本科同班，毕业后回县城当中学老师。
- **外貌**：圆脸，爱笑，说话快；手指甲总是干干净净。
- **欲望**：一个确定的未来——结婚、房子、孩子、周末能一起吃饭。
- **缺陷**：现实、急躁；她的等待有期限，这没有错。
- **弧光**：从“我等你” → 到“我看不到头” → 到结婚、退回份子钱。她不是反派，是另一个被时间追赶的人。
- **语言指纹**：“你什么时候能定下来”“我妈又问”“我不是嫌你穷”。

## 角色：陈立群（硕士导师）

- **身份**：省农业大学副教授，四十多岁，做小麦抗旱生理；实验室小，经费少，一年招一个学生。
- **外貌**：黑瘦，戴草帽下地，裤脚常年有泥；说话慢，爱说“不急，再做一遍”。
- **欲望**：做出一点真东西；把学生送出去。
- **缺陷**：清高、不会争经费；在学院里边缘化。
- **弧光**：从“你是块做科研的料” → 到追悼会上说“他是我带过最好的学生” → 到把麦生的数据要回去，接着做完。
- **语言指纹**：“下地”“数据不会骗人”“不急”“可惜了”。

## 角色：周世昌（博士导师）

- **身份**：江城农业大学教授，长江学者，小麦遗传育种/基因编辑；实验室三十多人，横向课题多。
- **外貌**：五十多岁，保养得好，衬衫熨得平整；说话快，爱用“格局”“产出”“时间节点”。
- **欲望**：保住帽子、拿到大项目、把实验室撑下去。
- **缺陷**：把人当产能；不是存心作恶，是系统里活得太久，麻木了。
- **秘密**：他自己也是“非升即走”熬出来的；他抽屉里也有安眠药。
- **弧光**：从组会上骂“你这三年干了啥” → 到追悼会上致悼词“勤奋、朴实、热爱科研” → 到第二天实验室照常打卡。
- **语言指纹**：“数据呢”“文章呢”“时间节点”“你要有格局”“我也是为你好”。

## 角色：张弛（同门）

- **身份**：直博生，本科 985，父母是高校教师；已发两篇一区。
- **欲望**：按期毕业，进高校，拿帽子。
- **缺陷**：不坏，只是从未理解“没有退路”是什么感觉。
- **作用**：镜子。他请麦生吃饭、借他试剂、帮他改论文；他的善意里带着不经意的优越。

## 角色：李强（发小）

- **身份**：初中毕业，在县城开装修公司，买房买车，二胎。
- **作用**：另一种“出息”。他递中华烟、抢着买单、说“读书人不一样”，每一句都像软刀子。
- **关键场景**：过年村口相遇，李强塞给麦生一条烟，说“你留着自己抽，别老熬夜”。麦生不抽烟，还是收下了。

## 角色一致性要点（C1—C10）

- C1：麦生对家里永远报喜不报忧；说“挺好”时，通常正在最难的时候。
- C2：他紧张时用手指推眼镜，推完还要再推一次。
- C3：他难受时不哭，只低头看手机，或者去洗手间用凉水冲脸。
- C4：父亲表达爱的方式是“钱够不够”；母亲是“吃了吗”；姐姐是“你别管”。
- C5：何静每次提结婚，都会先笑一下，再说话。
- C6：周世昌批评人时，先夸一句“你人很踏实”，再转折。
- C7：陈立群说“不急”的时候，往往是他自己也急。
- C8：麦生从不主动提“第一学历”，但别人一提，他耳朵会红。
- C9：他随身带着一穗麦子，用透明胶带缠过，放在书包夹层；后来放到工位信封，最后放进夹克口袋。
- C10：他死前没有留下遗书，只有手机备忘录三行字和一条没发出去的语音。
