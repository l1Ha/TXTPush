# 01 世界设定

> 本作的“世界”是这条横跨四洲、约二十八年的路线本身：地理、气候、国界与人情，共同构成主人公要对抗与相处的“自然”。

## 一、路线的地理底盘

从南到北、从西到东，一条**不被飞行打断**的连续路径：

1. 南美：智利蓬塔阿雷纳斯（麦哲伦海峡）→ 阿根廷 → 智利 → 秘鲁 → 厄瓜多尔 → 哥伦比亚；
2. 中北美：巴拿马（**达连隘口**在此断开）→ 哥斯达黎加 → 尼加拉瓜 → 洪都拉斯 → 危地马拉 → 墨西哥 → 美国 → 加拿大 → 阿拉斯加；
3. 跨海：**白令海峡**（美→俄，踩冬冰徒步）；
4. 亚洲：俄罗斯（**楚科奇—西伯利亚—乌拉尔，占全程最难的一段**）→ 哈萨克斯坦；**里海**（哈→阿塞拜疆，水上横渡）；
5. 欧洲：高加索 / 土耳其 / 东欧 / 中欧 / 西欧 → **英吉利海峡** → 英格兰赫尔。

## 二、硬性设定铁律（W1…Wn）

- **W1｜达连隘口无路**：巴拿马与哥伦比亚之间有一百多公里无公路的原始丛林，是泛美公路唯一的断口——只能徒步穿越，毒蛇、沼泽、武装人员并存；
- **W2｜白令海峡只在冬季“有路”**：一年中只有冬春之交，海面结成浮冰，才可能徒步渡海；冰随时开裂漂移，落水即生死；
- **W3｜国界与签证是真正的墙**：路线可跨国境数十次，每一次都要一张纸。尤其俄罗斯——没有许可，一步都走不了。地缘政治可以轻易冻结一个人的十年；
- **W4｜水是重复出现的考题**：里海、英吉利海峡——一个不擅长游泳的人，必须一次次越过水面；
- **W5｜时间是最大的代价**：原计划约 12 年，实际拖成 28 年；真正“在走”的约 15 年，其余消耗在等待、申请、搬迁与折返上；
- **W6｜补给靠人**：他推着一辆载物的小车，靠沿途陌生人接济、留宿、搭手前行——善意是这条路上最稳定的资源。

## 三、编年表（骨架）

| 时间 | 事件 | 意义 |
|---|---|---|
| 1969 | 生于英格兰赫尔 | 起点即终点 |
| 1998·11·01 | 自蓬塔阿雷纳斯出发，29 岁 | 远征开始；婚姻刚破裂 |
| 1998–2005 | 徒步纵贯南北美洲，穿越达连隘口 | 自然的第一次下马威 |
| 2006·03 | 与德米特里·基弗踏白令浮冰，美→俄 | 首次有人徒步跨越白令海峡；随即在俄被拘 |
| 2006–2010 年代 | 困于俄境与边境，签证长跑近十年 | 比自然更磨人的是制度 |
| 其后 | 穿哈萨克斯坦，横渡里海，越高加索入欧 | 重返“在路上” |
| 2026·11·02 | 推车回到赫尔母亲家，57 岁，初见 12 岁孙女 | 归家；一句关于善意的总结 |

## 四、日常细节清单（写作时兑现）

1. **行头**：一辆手推小车（载帐篷、睡袋、干粮、通讯与证件副本）；磨穿又补的靴子；
2. **吃与睡**：面包、罐头、当地人的一顿热饭；借宿的谷仓、消防站、民居地板；
3. **钱**：出发时仅约 500 美元；沿途靠打零工、赞助与接济；
4. **身体**：脚泡、冻伤、晒伤、蚊虫、脱水；落水后的失温；
5. **天气**：麦哲伦海峡的横风、达连的暴雨、楚科奇的极寒、里海的风浪；
6. **纸与章**：护照、签证、入境章、被没收又讨回的证件——他真正的“第二双腿”；
7. **通讯**：早期靠卫星电话与邮件，后期靠网络；与家人的距离由信号和时差丈量；
8. **语言**：英语、西班牙语、俄语的零星词句；更多时候靠手势与善意；
9. **人**：牧民、司机、边检、村妇、孩子——把他们写具体，是“99.9999%”的由来。

## 五、镜面原则（映射现实，靠代价显形）

路线上的每一道墙，都照见一种现实结构：国界 ↔ 身份与准入；签证长跑 ↔ 个体在制度前的渺小；28 年 ↔ 现代人对“效率/成功”的单一想象。所有映射都以**主人公付出的具体代价**（岁月、婚姻、亲情）显形，不靠旁白点题。
