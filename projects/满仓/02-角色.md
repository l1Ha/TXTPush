# 02 角色

## 关系网

- 满仓 ↔ 爹：信条的传递者与接受者——“胳膊拧不过秤砣”“地翻一遍，又是一年”；
- 满仓 ↔ 娘：温饱与亏欠的记忆——炒黄豆、榆钱馍、临终那句“地，别撂了”；
- 满仓 ↔ 秀：相守与亏欠——她替他守了半辈子的家与他缺席的岁月；
- 满仓 ↔ 念祖（子）：距离与重复——父辈离乡，子辈也离乡；父辈借债娶亲，子辈也借债、还多一套房；
- 满仓 ↔ 孙子：血脉重新接上的那一点——一穗青麦。

## 角色：陈满仓（主人公）

- **身份**：淮滨县农民，1962 年生；种地—打工—回乡，一辈子；
- **外貌标志**：一双手——裂口、指甲缝里的泥、冻开口子缠着胶布、老了发抖；走路时微微前倾，像总在逆风；
- **欲望（表层）**：让家里的日子“满起来”——有粮、有钱、有房、儿孙齐整；
- **需求（深层）**：被人记得他来过这片地；被“土”认领；
- **缺陷**：把“忍”与“扛”当成唯一的办法——所有的难受都往里咽，从不开口；
- **秘密**：他不怕穷，怕的是有一天，地不再需要他，他就什么都不算了；
- **人物弧光**：为“满”而活 → 为“扛”而活 → 为“守”而活 → 终于懂得：人一茬一茬地走，麦一茬一茬地长，这本身就是“满”；
- **语言指纹**：话极少，句子短；常复述爹的话；谈钱、谈地、谈天气时最利索；谈感情时只说半句；
- **与主线的关系**：唯一视角人物，全书即他的一生。

## 角色：秀

- 隔村人，脸圆、手巧、会纳鞋底；一生操劳，替满仓守家；语言指纹：不说苦，只说“习惯了”“不碍事”；临终想看自家地头的麦子。

## 角色：爹 / 娘

- 爹：一辈子跟土打交道的人；口头禅“河要发水，拦不住；可人不能跟着躺下”。娘：把最后一颗炒黄豆塞给孩子的母亲，代表温饱的记忆与亏欠。

## 角色：念祖（子）与孙子

- 念祖：被距离养大的一代，进城、买房、生子，重复父辈的弯腰；语言指纹：急、短、带城里的词，却越来越少回家；
- 孙子：在一穗青麦里与血脉突然对上的一代。

## 角色一致性要点（C1…）

- C1：满仓难过时不哭，先“往里咽”，最多说一句“没事”；
- C2：他一辈子复述爹的两句话（“秤砣”“地翻一遍又是一年”），遇事必用；
- C3：他衡量困难，永远先算“能不能扛”，再谈别的；
- C4：他提到地，语气立刻变软；提到城里，只说“不认得我”；
- C5：他从不主动要孩子的钱，反而总想着再塞给孙子；
- C6：他紧张或为难时，会蹲下来——拍掉膝盖上的土，再站起来说话。
