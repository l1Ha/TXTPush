# 01 世界设定

## 一、时空坐标

- **地点**：河南省信阳市淮滨县，淮河北岸某村（行洪区、平原农区，稻麦两熟）；
- **时间**：一九六二年前后至当下（近七十年，覆盖满仓的一生）；
- **区情**：地是淮河淤出来的，肥而怕水；弱筋小麦为地方特色；青壮年多赴南方、北方工地务工；村庄由“大锅饭”年代一路走到空心化。

## 二、硬性设定铁律（W1…Wn）

- **W1｜淮河会发水**：村子在滩区，水患是悬在头顶一辈子的东西；一次大水，能把一季庄稼、半间屋冲没；
- **W2｜地是命，也是拴人的绳**：分田到户后，地是一家人的根；“别撂地”是一代人的信条；
- **W3｜种地养不活一家人**：学费、药钱、彩礼，逼着一代人外出打工，留下妻儿老小；
- **W4｜政策与时代会变**：交公粮 → 取消农业税、发补贴 → 新农合 → 土地流转、空心化；个人只能跟着走；
- **W5｜代际接力是循环的**：自己娶亲借债，儿子娶亲又借债、还要县城的房——一代人用同样的姿势弯腰；
- **W6｜时间只会往前，不等人**：孩子在打工的年头里长大，父母在赶回来的路上老去、死去。

## 三、编年表（大时代 / 本地 / 私史 三线咬合）

| 时间 | 大时代 / 本地 | 私史 |
|---|---|---|
| 1962 | 淮河大水后，困难时期将过 | 满仓出生，取名“满仓” |
| 1960s–70s | 大锅饭、生产队、露天电影 | 光脚童年、断粮、榆钱馍 |
| 1980s 初 | 分田到户（包产到户） | 家中第一次吃饱；辍学、学种地 |
| 1980s | 交公粮；淮河再发水 | 十八岁亲历水灾；爹的“秤砣”论 |
| 1980s 末 | 农村婚嫁 | 二十三岁娶秀；生子念祖、添闺女 |
| 1990s | 打工潮兴起 | 三十二岁第一次出门，此后十余年在外 |
| 1990s–2000s | 留守妇女与儿童成普遍现象 | 一年回一次；曾从脚手架摔下 |
| 2000s | 取消农业税；新农合推行 | 爹、娘先后去世 |
| 2010s | 县城购房、高彩礼、土地流转 | 掏空积蓄为儿子娶亲、买房 |
| 2010s–2020s | 村庄空心化 | 秀病逝；满仓独居、成为留守老人 |
| 当下 | 乡村振兴、城乡流动 | 孙子一代出生；满仓“看麦子” |

## 四、日常细节清单（正文已落地）

1. **吃食**：大锅饭、稀粥、榆树皮面掺苞谷面、炒黄豆、白馍、馍就咸菜；
2. **劳作**：放牛、拾麦穗、扶犁、撒种、看天、翻淤地、下种、交公粮；
3. **钱与物价**：娶秀花 400 元；彩礼涨到十几万；工钱一张张攒着带回；
4. **器物**：土坯房、长凳、晒场白布、蛇皮袋、工棚、脚手架、胶布缠手、旧轮椅、收音机；
5. **交通**：一挂鞭炮的两桌酒；一天一夜的火车与春运；
6. **病与老**：裂口的手、新农合、县医院、市里看病、药；
7. **村庄设施**：西坡的林子与坟、滩上的土、锁着的门、空掉的白昼；
8. **说话方式**：中／白／咋／撂／瘪／胳膊拧不过秤砣；
9. **季节与天气**：七天七夜的雨、半个月不退的水、麦黄、霜前雨后；
10. **仪式**：娶亲、摆酒、垒坟、磕头、坟头朝着自家的地。

## 五、镜面原则（映射现实，靠代价显形）

地与水 ↔ 生存与匮乏；打工与留守 ↔ 城乡二元与家庭离散；高彩礼与县城购房 ↔ 代际接力与婚姻市场压力；空心化与独居 ↔ 老龄化与养老困境。全部以**人物付出的具体代价**（岁月、亲情、健康、积蓄）显形，不靠旁白点题。
