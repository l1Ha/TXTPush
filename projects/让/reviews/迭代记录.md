## 意见处置（采纳 / 部分采纳 / 驳回）

| 评审意见 | 处置 | v4 落点 |
|---|---|---|
| 儿子功能化，应有独立压力 | 采纳 | 阳台加一句：「我们组今年要动两个人。」 |
| 素梅只是反对者，应见其共谋面 | 采纳 | 「他就是这号人。」；「我怨了他十年……后来我跟自己说，认了吧。」 |
| 语言过于平均，缺感官与失控 | 采纳 | 离合「脚底下突突地跳」；手机放重「杯盖跳了一下」 |
| 鸡蛋未贯穿 | 采纳 | 报名窗口磕鸡蛋，另一个塞回兜里；结尾「还是温的」 |
| 档案袋太整齐，像展品 | 采纳 | 烟盒纸滑出，捡起来吹灰 |
| 结尾缺生理触发 | 采纳 | 场地里「离合哄了一下，又稳住」 |
| 结构「举例式」 | 部分采纳 | 保留双时间面（全触发式闪回会碎），强化档案袋的触发功能 |
| 重复物件过度编织 | 部分采纳 | 不删核心物件；以「散落感」换「整齐感」，降低设计味 |
| 删「你不是让，你是怕」 | 驳回 | 全篇唯一被说破处，且为人物吵架之言；以素梅共谋线平衡，不删 |
| 标题改《不说想》 | 驳回 | 生造构词，不利口播与传播；备选见 `experiments/结局与标题.md` |
