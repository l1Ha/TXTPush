# 发布增长方案（八篇短篇 × 《冬小麦》）

> 原则：**文学质量不动，入口改头换面。** 正文保持现稿；标题、首屏、导语、封面、节奏、渠道、金句，全部按「吸引路人」重做。
> 适用账号：微信公众号（首发）+ 知乎 / 今日头条 / 百家号 / 豆瓣 / 小红书（延后分发）。

## 二、首屏导语（放在文首，60—100字，正文前）

- **代买**：他常在楼下彩票店代买一注「老号」，买了十一年。开奖那晚，老板回了四个字：「哥，你中了。」第二天一早，老板一个人上了去杭州的高速。
- **看孩子**：做月嫂的母亲把两岁儿子免费托付给邻居夫妇；孩子被开水烫伤，没有第一时间送医。一张作业本上撕的纸，和一场官司，把两户好人拆开。
- **对门**：有人问：你俩到底是什么关系？他说：老同事。她在厨房补一句：对门。他们同住十四年，各住一间卧室，开销 AA 制，存折各写各的名。
- **漏粉**：立冬一过，61 岁的老粉匠在集上捏了捏机器粉条，回家翻出锈了十几年的漏瓢。四十八个眼儿，他用钉子一个一个敲通。那半摞搁了十二年的蜂窝煤，一直没还回他。
- **家人们**：老温的手机里，有个做销售的姑娘每天管他叫「温爸爸」，问他老伴的血糖。三个月，两万八。直到女儿翻开了那部手机。
- **自愿放弃**：十一年，她每月多拿二百块，代价是抽屉里那张自己按了手印的「自愿放弃」。五十一岁这年，她走进稽核科，说了一句：「我投诉我上班的店。」
- **两个钟头**：她照顾瘫痪的老伴八年，第一次被放出门，是两个钟头。她洗了八年来第一个澡。回来时，老伴给她留了半个橘子。
- **让**：他让出了电大名额、南墙的房子、去东莞的车票、街口那间门面——每一次都有一个体面的理由。他这辈子最熟练的一句话是「你拿主意」。六十岁那年，他去驾校报了个名。

## 三、发布排期（15 天短篇冲刺 + 14 期连载）

原则：1 篇一个群发周期（订阅号每天 1 条），强钩子打头，温情与沉重大小交叠；发布时间统一 **晚 8:00—9:30**（手机阅读高峰）。

| 天 | 发布 | 理由 |
|---|---|---|
| D1 | 《代买》 | 825 万 + 一夜暴富 + 背叛，最普适的钩子 |
| D3 | 《看孩子》 | 社会争议题，评论区最容易炸 |
| D5 | 《对门》 | 与当天新闻余温重合，先温暖一波 |
| D7 | 《家人们》 | 每代人都有「被骗的爸妈」，转发率高 |
| D9 | 《漏粉》 | 治愈款，喘息一节 |
| D11 | 《自愿放弃》 | 打工人共情题 |
| D13 | 《两个钟头》 | 照护者共鸣，转发给兄弟姐妹的题 |
| D15 | 《让》 | 文学性最强，做「压轴惊喜」 |
| D17 起 | 《冬小麦》连载 | 隔天 1 期 ×14，连载期间不再插短篇；合集单篇留完结后发 |

每篇发布当晚，在评论区自己预埋 1 条话题（见第五节表格）。

## 四、多渠道分发（公众号首发 72 小时后再搬）

| 平台 | 形式 | 要点 |
|---|---|---|
| 知乎 | 以「回答」出现：如「你听过最让人后背发凉的判决是什么？」「父母被私域直播骗过吗？」 | 正文照搬，结尾引导公众号；挑选 3—5 个问题长期占位 |
| 今日头条/百家号 | 原文 + 公众号标题 | 标题再粗暴一点；开原创前确认首发声明 |
| 豆瓣 | 日记 + 豆瓣阅读投稿 | 面向文学读者，用文学标题 |
| 小红书 | 只发「金句卡」+ 三行小注 | 每篇一张卡，链接到主页，不做全文搬运 |
| 期刊投稿 | 《让》《对门》《漏粉》投文学期刊（人民文学 / 十月 / 钟山） | 鲁奖参评路线独立于流量路线，互不打架 |

## 五、涨粉与互动机制

1. **文末固定三件套**：上一篇链接 + 系列合集（置顶）+「回复关键词看全集」（如回复「代买」）。

| 看孩子 | 「邻居帮忙看孩子，出了事该不该赔？」 |
| 对门 | 「你能接受父母这样养老吗？」 |

| 自愿放弃 | 「该不该让家里老人回去补社保？」 |

| 让 | 「你有没有'让'出去过什么？」 |

3. **封面统一系列感**：深底、白字、一件物品特写（一张准考证 / 两张存单 / 一只鸡蛋 / 一只漏瓢）。用创客贴/Canva 做一张母版，换物换字即可。
4. **金句卡**：见 `docs/金句卡.html`，截图后朋友圈/小红书/群转发；每篇一张。
5. **连载追更**：《冬小麦》每期末尾放「下一期预告一句话」；第 1 期文末放人物关系图（文字版即可）。

## 六、合规与底线（照抄上期不变）

- 发布时**必须勾选**「AI 生成（合成）内容」声明；原创声明按平台规则勾选；
- 《冬小麦》第 13 期（自杀情节）发布时留意审核提示，必要时调整顺序；
- 多平台分发不得早于公众号首发（保住原创标）。

## 七、30 天指标（冷启动参考）

- 每篇 48 小时阅读 ≥ 500；评论 ≥ 10；
- 30 天新增关注 300—1000；出现 1—2 篇 5000+ 的「小爆款」；
- 指标只约束动作，不约束写作：**写的时候不为流量改一个字，发的时候不为体面少改一个字。**
