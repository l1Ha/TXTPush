# 章节写作与钩子

## 一、单章的完整闭环

每一章都是一集「剧」：**进入状态 → 冲突升级 → 局部结算 → 抛出下一问**。

- **章首**：尽快进入场景（第一段内出现具体的人、地点与压力），不要用前一章的总结开场；
- **章中**：至少一次局势变化（谁占了上风、谁改变了主意、出了新信息）；
- **章末**：落在钩子上，收在动作、悬念或情绪的最紧处，而不是复盘。

## 二、章末钩子八型（轮换使用，同类不连用）

| 型 | 机制 | 示例 |
|---|---|---|
| 悬念钩 | 抛出未解的问题 | 门后面传来母亲的声音——可母亲已去世三年。 |
| 反转钩 | 颠覆本章的理解 | 他打开信封，里面是自己笔迹的举报信。 |
| 危机钩 | 危险迫近 | 脚步声停在了他的房门外。 |
| 决定钩 | 主角下决心 | 他拿起电话，拨通了那个号码。 |
| 揭示钩 | 关键信息曝光一半 | 「你父亲的档案，最后两页是空的。」 |
| 情感钩 | 情感关系变化 | 她把钥匙放在桌上，说：「这次别回来了。」 |
| 时间钩 | 倒计时开始 | 距离公示截止还有四十八小时。 |
| 意象钩 | 用物件/自然完成情绪收束 | 雪落在账本上，把数字一笔笔盖住。 |

钩子要**从本章内部长出来**（与人物目标、代价直接相关），而不是硬造惊悚。每 3 章至少一次强钩（反转/危机/揭示）。

## 三、场景内的「转」：微冲突写法

一场戏里要有人赢/输/变。写法：**目标 → 阻力 → 转折 → 结算**。

- 目标：这场戏他想拿到什么（问出地址、借到钱、见到人）；
- 阻力：对面为什么不能给（不知道、不愿、不敢、给不起）；
- 转折：出现了什么新变量（一个电话、一句旧事、第三个人的出现）；
- 结算：谁让步了，代价是什么。

**没有结算的场景是不完整的**——读者会觉得「这段看完了什么也没发生」。

## 四、章长与信息量

- 中文连载常见章长 2000~4000 字；单章信息量以「一个场景变化 + 一个钩子」为基准；
- 超过 5000 字的章，检查是否是两个场景没拆开；
- 低于 1500 字的章，多半是场景没写透（缺阻力或缺结算）。

## 五、开篇三章特别规则

1. 第一章前 300 字：人物落地（一个动作）+ 麻烦显形（一个信号）；
2. 第一章内：至少一次小的冲突结算（证明「这是一本会发生事情的书」）；
3. 前两章内：让读者看见主角的「特殊之处」——不是最强，而是最值得看（执念、手艺、视角、幽默感）；
4. 第三章末：抛出全书长线问题（读者开始追的具体疑问）。

## 六、转场与留白

- 场景与场景之间学会跳：删掉起床、赶路、入睡等过渡段；
- 用回目/分节符号（空行、﹡﹡﹡）切时间跨度；
- 留白：不写他如何走出门，直接写他已经站在人群里——把过渡留给读者。

## 七、常见错误

- 章末复盘：把本章总结一遍再收尾，钩子被稀释；
- 每章同一种钩子（全是「突然，一个声音传来」）；
- 章内无变化：聊天聊了一整章，只有信息没有输赢；
- 把高潮写进章首、把过场留到章尾（节奏倒挂）；
- 为凑字数写「人物缓慢地走回家」类段落。

## 八、实操清单

1. 给每章标注钩子类型，检查是否连用同类；
2. 检查每章是否至少一处局势变化；
3. 删掉所有章末总结与「下一章预告」式句子；
4. 挑一章拆成「目标/阻力/转折/结算」，缺项即补；
5. 前 300 字检查：有没有具体动作与麻烦信号？

## 本篇要点速查

- 单章闭环：进入 → 升级 → 结算 → 抛问；
- 钩子八型轮换，强钩每 3 章一次；
- 场景四步：目标 / 阻力 / 转折 / 结算；
- 章长基准 2000~4000 字，超了拆、短了补；
- 开篇三章：落地 → 特殊之处 → 长线问题。
