# 人物关系与对手设计

## 一、关系网：故事的第二骨架

把主要角色两两连线，每条线上标注一种关系动词：**依赖 / 对立 / 隐瞒 / 亏欠 / 竞争 / 救赎**。
检查三件事：

1. 主角与每个人之间，是否存在**至少一次立场变化**（盟友变对手、对手变同路人）？
2. 关系网里是否有**闭环结构**（A 欠 B，B 依赖 C，C 恨 A）？闭环是情节自动供能的引擎；
3. 有没有「只跟主角单线联系」的孤岛角色？孤岛要么并入网络，要么删掉。

## 二、对手设计：反派是主角的镜子

三步法：

1. **同一问题的不同答案**：主角与反派面对同一个世界、同一类困境，给出了相反的解法。写反派时先问：如果我是他，我会觉得自己错在哪？
2. **结构化力量**：反派掌握什么（资源/信息/合法性/人心），主角缺什么，这个差值就是全书紧张感的来源；
3. **人性时刻**：给反派至少两个「不像反派」的瞬间（对宠物的温柔、遵守某个旧承诺、对亡妻的沉默）。恶越具体，越可怕。

**禁止**：反派降智、反派在关键节点放弃优势、反派的动机是「纯粹的恶」。

## 三、对手的梯度设计

长篇需要一组成阶梯的对手，而不是一路打怪：

| 层级 | 功能 | 例子 |
|---|---|---|
| 门口对手 | 第一章制造麻烦，展示主角的处境 | 恶邻、刁难的上司、村口的地痞 |
| 阶段对手 | 推动每一卷的成长与改变 | 竞争者、旧仇人、体制内的守门人 |
| 镜像对手 | 与主角共享困境，给出相反的答案 | 走上歧路的同门、出卖过朋友的老友 |
| 终极对立 | 世界规则的化身，主题的顶点 | 掌门、体制的最高点、时间本身 |

每换一级对手，主角必须付出上一级学到的代价与成长——否则战斗就是重复。

## 四、盟友与情感线

- **盟友的作用是照出主角**：不同盟友身上各有一种主角缺少的品质；
- **情感线（爱情/亲情/友情）必须改变情节走向**：删掉这条线，如果主线毫无变化，说明它只是装饰；
- **情感推进靠共同经历而非对话表白**：一起扛过的事排第一，聊出来的感情排最后；
- **信任危机是情感线的好燃料**：隐瞒、误会、立场冲突——但要保证误会来自性格，而不是作者硬造。

## 五、群戏调度

三人以上的场景容易散。调度口诀：**一人主导、一人反应、一人观察**。每个群戏场景开写前，给每人分配一个功能（推动/质疑/沉默的证人），并明确「这场戏结束时谁知道了新信息」。

## 六、常见错误

- 反派只出现在主角要升级的时候；
- 全员对主角态度一致（全世界围着他转）；
- 感情线靠外貌与运气启动；
- 关系网十年如一日，没人背叛也没人和解；
- 对立力量是抽象名词（资本、体制），没有一张具体的人脸。

## 七、实操清单

1. 画关系网（≥6 人），每条线写关系动词与一次立场变化；
2. 按梯度表安排四层对手，写进大纲钩子栏；
3. 给反派写一段 200 字自白，再写两个「人性时刻」；
4. 检查情感线：删掉它，主线是否改变？不改变就修改或删除；
5. 挑一场群戏，标注三人的功能与场景结束后的信息差。

## 本篇要点速查

- 关系动词：依赖 / 对立 / 隐瞒 / 亏欠 / 竞争 / 救赎；
- 反派 = 同一问题的相反答案 + 结构化力量 + 人性时刻；
- 对手四梯度：门口 / 阶段 / 镜像 / 终极；
- 盟友照出主角，情感线必须改变情节；
- 群戏口诀：主导 / 反应 / 观察。
