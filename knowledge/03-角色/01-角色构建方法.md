# 角色构建方法

## 一、角色的五件套

一个能立住的主要角色，必须同时具备五样东西（缺一样，人物就会在某个情节里「塌掉」）：

1. **欲望（想要）**：表层目标，能说出口的（赚钱、复仇、考出去、娶她）；
2. **需求（需要）**：深层缺口，常常说不出口的（被看见、被原谅、不再害怕）；
3. **缺陷**：阻碍他得到需求的习惯或信念（逞强、讨好、不信任任何人）；
4. **秘密**：读者或他人不知道的信息，悬念与反转的燃料；
5. **弧光**：从起点到终点，他身上必须改变的那一样东西。

**黄金法则：让欲望与需求冲突。** 他想要的东西（留在城里）恰恰让他得不到需要的东西（家人的原谅）——冲突就从人物内部生长出来，而不是靠外部事件硬推。

## 二、人物小传：写七页，用三句

小传写到能回答这些问题即可停笔：他童年的哪个画面塑造了他？他最后一次哭是什么时候？他钱包里有一张什么？他撒谎时的习惯动作？

**小传的用途不是塞进正文**，而是在你写对话卡壳时，能立刻知道「这个人此刻会怎么说、怎么做」。

## 二点五、弧光的四种形态

| 形态 | 起点 → 终点 | 适用 |
|---|---|---|
| 正弧光 | 缺陷 → 直面并克服（付出代价后改变） | 成长型主角，最主流 |
| 平弧光 | 信念不变，被世界反复考验得更加澄澈 | 群像、行业、现实题材（主角是定盘星） |
| 堕落弧光 | 信念 → 被欲望吞噬 | 反派起源、悲剧、暗线 |
| 幻灭弧光 | 幻想 → 看清真相而不被击垮 | 解谜、祛魅题材 |

**铁律**：弧光的每一步都由一个**选择**推动，而不是由时间流逝或别人开导推动；改变必须付代价。

## 三、外貌与标志：一个可记忆的细节

不要写「英俊/美丽/高挑」这类无信息量的词。给每个主要角色**一个可复看的标志**：

- 一个身体特征（左手小指的旧疤）；
- 一个物件（掉漆的打火机、总是背着的帆布包）；
- 一个动作习惯（紧张时转戒指、说完狠话补一句玩笑）。

标志在情绪转折处反复出现，就会自动变成意象（见 `01-概论/03`）。

## 四、配角三原则

1. **每个配角有一句属于自己的台词**——让人记得住的那种；
2. **每个配角有自己的议程**——出场时他在忙自己的事；
3. **群像要有一张对照表**（姓名—身份—立场），避免次要人物前后换名、换性格。

## 五、反派与对立力量

- 反派的动机必须**从他自己的立场上成立**（见 `02-人物关系与对手设计`）；
- 反派的力量要**结构化**：他掌握的资源、信息、合法性；
- 最强的反派会让主角**学到他的一部分**——对立面是同一种人性的另一种答案。

## 六、一致性要点（编号化）

角色文档末尾必须输出「角色一致性要点」清单，编号 C1、C2……供写作与审校引用，例如：

- C1：林默从不主动夹菜，只在别人递过来时接；
- C2：苏晚只在极度紧张时使用书面语；
- C3：老周永远不会直呼任何人的全名。

一致性要点是**行为的边界**，不是人设标签。它们让角色在几十万字里保持同一副骨头。

## 七、常见错误

- 人设堆砌：档案写满三页，出场只说功能台词；
- 全员同一智商/同一幽默感/同一声调；
- 主角没有缺陷，或缺陷只用来卖萌；
- 弧光靠台词宣告（「我成长了」）而不是靠选择证明；
- 配角的唯一作用是递消息、当背景或谈恋爱。

## 八、实操清单

1. 给每个主要角色填五件套，检查欲望与需求是否冲突；
2. 为每人分配一个标志（特征/物件/动作三选一），标明首次出场处；
3. 写一段 200 字的小传，不许出现形容词堆砌；
4. 列配角对照表（≥8 人），每人写一句属于自己的台词；
5. 起草一致性要点（≥6 条），并挑一条在下一章里实际用到。

## 本篇要点速查

- 五件套：欲望 / 需求 / 缺陷 / 秘密 / 弧光；
- 欲望与需求必须冲突；
- 一个标志胜过十句外貌；
- 配角三原则：一句台词、自己的议程、对照表；
- 一致性要点编号化（C1…Cn），行为边界而非标签。
