# 对话与语言指纹

## 一、对话只干三件事

一句对话（或一段对话）必须至少完成一项，最好同时完成两项：

1. **推进信息**：给出读者需要知道的事（且是以人物的立场给出的，不是百科）；
2. **塑造人物**：暴露说话者的性格、处境、欲望或隐瞒；
3. **制造张力**：留下未说出口的东西，让下一句有悬念。

只完成「客气寒暄」或「复述已发生剧情」的对话，删。

## 二、语言指纹：让读者闭眼能认出谁在说话

给每个主要角色设计一套**语言指纹**，至少覆盖四个维度：

| 维度 | 可调的手柄 | 示例对比 |
|---|---|---|
| 词汇 | 口头禅、行话密度、脏话与敬语 | 老警察：「啧」；白领：「这个事儿吧」 |
| 句长节奏 | 短促如刀 / 绵长缠绕 | 打手短句连发；教授长句套从句 |
| 逻辑习惯 | 爱反讽 / 爱说教 / 爱绕圈 / 直奔结论 | 商人先铺垫再报价；少年直来直去 |
| 态度切换 | 对上级/平级/弱者的不同口气 | 同一个人，对领导谄媚、对下属刻薄 |

**检验方法**：遮住说话人名字，读者能否分辨是谁在说话？不能，就说明指纹太弱。

## 三、潜台词：不说的比说的重要

好的对话是「冰山」——纸面是冰山一角，水下是人物真正的动机与恐惧。

- 想挽留的人，往往说「你走吧」；
- 想炫耀的人，常先抱怨「这也没什么」；
- 心虚的人，会主动提起一件无关的小事来转移话题。

**写法**：让人物说与真实意图相反的话，用动作与沉默泄露真相。情绪越剧烈，台词往往越短、越跑题。

## 四、节奏与控制

- **少用「他说道」**：连续对话可省略提示语，或用动作代替（「她把烟按灭。」）；
- **打断与留白**：真实的对话充满重叠、停顿、答非所问，适度使用能提速或制造尴尬；
- **动作插入**：在对话间插入一个小动作，能同时控制节奏与暴露情绪；
- **别让每个人都长篇大论**：一段超过四五行的话，读者会跳过。长台词只在人物情绪顶点偶尔使用。

## 五、长篇对话的注意事项

- **信息分批给**：一次对话只交出必要的一块信息，剩下留到后面；
- **避免解释腔**：没人会向同事解释他自己行业的基础常识。用行话与省略暗示读者；
- **问答不平等**：一方在追问，一方在回避，张力自然产生；
- **对话要有后果**：谈完之后，人物必须做出决定或改变立场，否则这场对话是空的。

## 六、常见错误

- 所有人说话一个腔调，像同一个作者在自说自话；
- 用对话直接解释设定与剧情（「如你所知，我们的皇帝……」）；
- 台词里塞满人生哲理，人物变成作者传声筒；
- 一问一答、彬彬有礼，毫无冲突；
- 口头禅用得太密，变成滑稽模仿。

## 七、实操清单

1. 为每个主要角色写一页语言指纹卡（词汇/句长/逻辑/态度）；
2. 做「去名字测试」：随机抽 5 句台词，遮名验证可辨性；
3. 挑一场关键对话，把台词的「显意」与「潜意」分两列写出来；
4. 全文搜索「如你所知」「其实」「也就是说」等解释性词，能删就删；
5. 检查每场对话结束后，人物立场或关系是否发生了变化。

## 本篇要点速查

- 对话三功能：推信息 / 塑人物 / 造张力，缺一即删；
- 语言指纹四维度：词汇 / 句长 / 逻辑 / 态度；
- 潜台词：让人物说不出口的话，比说出口的更有力；
- 节奏靠动作、停顿与打断，长台词慎用；
- 对话必须有后果——谈完就有人改变。
