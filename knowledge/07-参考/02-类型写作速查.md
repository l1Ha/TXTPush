# 类型写作速查

> 按主类型查：核心承诺 / 必给要素 / 节奏建议 / 高频雷点。更细的写法见 `10-题材模块/`。

## 言情

- **核心承诺**：关系的拉扯与确认，情绪浓度。
- **必给要素**：可信的心动理由；势均力敌的张力；关系的推进与回退。
- **节奏**：前期建立化学反应，中期制造阻碍与误会，后期确认与和解。
- **雷点**：爱情来得没有理由；配角纯工具；用误会灌水。

## 悬疑推理

- **核心承诺**：谜题、公平线索、解谜快感。
- **必给要素**：可解的问题；公平埋线的线索；动机合理的凶手。
- **节奏**：案发 → 调查受挫 → 线索汇聚 → 反转 → 揭示。
- **雷点**：线索不公平；凶手半路空降；靠巧合破案。

## 玄幻奇幻

- **核心承诺**：成长与力量快感、世界奇观。
- **必给要素**：有代价的力量体系；清晰的等级/规则；独特的世界质感。
- **节奏**：入门 → 受挫 → 升级 → 更大舞台，阶梯式放量。
- **雷点**：升级全靠送；体系无代价；数字通胀。

## 都市现实

- **核心承诺**：真实处境里的翻身/坚守/和解。
- **必给要素**：钱、流程、称呼的质感；行业两难；阶层与处境的真实。
- **节奏**：困境 → 应对 → 博弈 → 代价与和解。
- **雷点**：悬浮职场；金手指硬拗；新闻腔代替人物视角。

## 历史

- **核心承诺**：时代质感 + 个人命运的交织。
- **必给要素**：可信的时代器物与观念；权力结构的真实；小人物与大时代。
- **节奏**：时代背景铺陈 → 卷入冲突 → 抉择 → 命运落定。
- **雷点**：现代人穿越腔；史实硬伤；用现代价值观硬评古人。

## 武侠仙侠

- **核心承诺**：侠义、师承、江湖规则、意境。
- **必给要素**：有规矩的江湖；恩义与恩怨的因果；武学/修行的逻辑。
- **节奏**：入江湖 → 结恩仇 → 历练 → 决战与超脱。
- **雷点**：只有打斗没有江湖；恩怨无根；境界只是数字。

## 科幻

- **核心承诺**：新设定下的推演与惊奇。
- **必给要素**：自洽的设定；把设定推演到社会与个人；惊奇的画面。
- **节奏**：抛出设定 → 展示后果 → 冲突升级 → 思想实验落地。
- **雷点**：设定只做布景；推演不落地；术语堆砌替代故事。

## 通用自查

- 你的核心承诺是什么？在哪一处违约？用什么补偿？
- 前三章是否完成「麻烦落地 / 展示应对 / 长线问题」？
- 反派与配角是否各自成立，而非类型零件？
- 结尾是满足承诺，还是偷换承诺？

## 本篇要点速查

- 先满足类型承诺，再做一次属于自己的偏离；
- 每个类型有其必给要素与专属雷点；
- 差异化的关键在「具体」：行业、地域、身份、时代；
- 结尾要对得起封面上给读者的承诺。
