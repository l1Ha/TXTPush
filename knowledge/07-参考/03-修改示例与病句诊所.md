# 修改示例与病句诊所

## 一、改稿三遍法

先大后小，不要一上来抠字：

1. **结构遍**：看主线、节拍、代价曲线是否成立（删段、并章、调序）；
2. **场景遍**：看每场戏是否推进、是否有目标—障碍—结果、钩子是否兑现；
3. **句子遍**：删虚词、换陈词、修语病、统一标点。

**原则**：不要在结构没定的时候雕句子——白费。

## 二、常见病句与改法

| 病句 | 问题 | 改法 |
|---|---|---|
| 他的心情非常地复杂难言，无法用语言来形容。 | 抽象 + 越描越虚 | 他张了张嘴，把烟又塞回口袋。 |
| 在经过了漫长而又艰难的跋涉之后，他们终于到达了目的地。 | 「在……之后」冗赘 | 他们到了。 |
| 她缓缓地轻轻地推开了那扇沉重的木门。 | 副词堆叠 | 她推开门。（必要时「轻轻」二选一） |
| 由于天气的原因，所以因此活动取消了。 | 关联词杂糅 | 因为天气，活动取消了。 |
| 他大约二十岁左右。 | 「大约」与「左右」重复 | 他二十岁上下。 |
| 他的脸色显得十分地苍白。 | 弱动词 + 副词 | 他脸色白得像纸。 |
| 听到这话，他被深深地感动了。 | 被动 + 抽象 | 听到这话，他别过脸去。 |

## 三、冗余与虚词

- 删「进行、作出、给予、加以」等空壳动词：把「对文件进行审核」改为「审核文件」；
- 删程度副词的一半：「非常、十分、极其、格外、异常」；
- 删「的」字长链：三个「的」以上拆句；
- 删「了」的滥用；删「在……的情况下」「就……而言」等公文腔。

## 四、语病诊断五类

1. **搭配不当**：「提高……水平」可以，「提高……速度」→「加快……速度」；
2. **成分残缺**：缺主语/宾语（「经过讨论，使我们达成一致」→ 去掉「使」）；
3. **语序不当**：「一个漂亮的她买的包」→「她买的一个漂亮的包」；
4. **句式杂糅**：「原因是……造成的」二选一；
5. **指代不明/歧义**：「小王告诉小李，他的书丢了」——「他的」指谁？

**方法**：把长句拆到最短，主谓宾各归其位，病自现。

## 五、标点与文本卫生

- 中文正文用**全角**标点：，。！？：；「」《》……——；
- 省略号用 `……`（六个点或两组的 `……`），不用 `...`；破折号用 `——`，不用 `--`；
- 引号内外标点关系：完整引用，句号在引号内；否则在外；
- 数字、专名前后统一（全角/半角、有无空格）；
- 清除：残留批注、TODO、占位符（「此处补充」）、模型腔残句、重复粘贴的整段。

## 六、删改练习

取一段 200 字初稿，做三次减法：

1. 第一遍删掉所有形容词与副词，看主干是否还立得住；
2. 第二遍把抽象的「心理判断」全部换成可观察的动作/细节；
3. 第三遍把长句拆成短句，再挑一处merge回长句，制造节奏。

对比三版，通常第二、三版合并后最有力。

## 七、实操清单

1. 按「结构—场景—句子」三遍过稿，不要越级；
2. 全文搜索虚词与空壳动词，逐个删减；
3. 用五类语病清单抽查长句；
4. 统一标点与数字格式，清除所有残留批注；
5. 随机抽一段，做一次「删形容词 + 换动作 + 调句长」的重写。

## 本篇要点速查

- 改稿先结构、再场景、最后句子；
- 病句五类：搭配 / 残缺 / 语序 / 杂糅 / 歧义；
- 删空壳动词、程度副词、「的」字长链；
- 标点用全角，省略号 `……`、破折号 `——`；
- 清除批注、TODO、占位符、模型腔残句。
