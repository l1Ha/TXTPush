# 类型全景与作品定位

## 一、类型是「读者约定」，不是标签

类型（genre）的本质是一份**读者预期合同**：读者拿起悬疑小说，就默认会有谜题与解谜的快感；拿起言情，就默认要看关系的建立、破裂与和解。写作不是必须遵守合同，但要**先知道合同写的是什么**，再决定在哪一条上违约、用什么补偿读者。

| 类型 | 核心承诺（读者要的） | 常见雷点 |
|---|---|---|
| 言情 | 关系的拉扯与确认，情绪浓度 | 爱情来得没有理由；配角纯工具 |
| 悬疑推理 | 谜题、公平线索、解谜快感 | 线索不公平；凶手半路空降 |
| 玄幻奇幻 | 成长与力量快感、世界奇观 | 升级全靠送；力量体系无代价 |
| 都市现实 | 真实处境里的翻身/坚守/和解 | 悬浮职场；金手指硬拗 |
| 历史 | 时代质感 + 个人命运的交织 | 现代人穿越腔；史实硬伤 |
| 武侠仙侠 | 侠义、师承、江湖规则、意境 | 只有打斗没有江湖；恩怨无根 |
| 科幻 | 新设定下的推演与惊奇 | 设定只做布景，推演不落地 |

> 更细的写法要点见 `10-题材模块/`（`--genre` 选择后自动注入）。

## 二、定位三轴

在动笔前，给作品写下三根轴的取值，它决定你要查什么资料、在哪些地方较真：

1. **距离轴**：与现实的距离（现实/近现实/完全架空）——越架空，越要在人性与逻辑上真实；
2. **温度轴**：冷（克制、留白、冷峻）↔ 暖（明亮、治愈、励志）——全书一致，别第 3 章冷峻第 9 章鸡汤；
3. **浓度轴**：信息密度与情节速度（慢炖/标准/快节奏）——决定章节长度、场景数量与钩子密度。

## 三、目标读者与卖点

- **读者画像**：他们读过什么？厌倦什么？为什么点开你的书？写下来，贴在文档顶部。
- **差异化卖点**：同一类型里，你的书哪里不一样？「更真实的行业细节」「反转结构」「罕见的地域背景」「双主角镜像设计」都算。
- **一句话卖点（Logline）**：谁 + 想要什么 + 被什么挡住 +  stakes（输掉会失去什么）。能背下来，才算定稿。

## 四、开篇定位：前三章决定生死

新读者给一本小说的机会通常只有前三章：

- 第一章：主视角人物登场 + 一个具体麻烦落地 + 一个只属于本书的「气味」（语言、地域、行业、时代感）；
- 第二章：展示主角的应对方式（人物塑造最高效的段落），拉高麻烦的代价；
- 第三章：给出全书的长期问题（读者愿意追一整本书的那个东西）。

## 五、常见错误

- 类型混搭但没有主类型：读者不知道自己在读什么；
- 承诺不符：封面上是轻喜剧，正文是苦情大戏；
- 全程模仿爆款设定，差异点只有「更用力」；
- 把文学性当作反类型的理由——反类型的前提是先满足类型读者的基本预期。

## 六、实操清单

1. 写下类型主标签 + 一个副标签；
2. 用上表核对：我的核心承诺是什么，违约处在哪，补偿是什么；
3. 定位三轴各写一句；
4. Logline 压缩到 50 字内并朗读三遍；
5. 检查前三章是否分别完成「落地/应对/长线问题」三件事。

## 本篇要点速查

- 类型 = 读者预期合同：先满足，再违约；
- 三轴定位：距离 / 温度 / 浓度；
- Logline = 谁 + 想要什么 + 被什么挡住 + 失去什么；
- 前三章任务：麻烦落地 → 展示应对 → 抛出长线问题。
