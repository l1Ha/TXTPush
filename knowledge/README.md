# TxtPush 通用小说写作知识库

面向各类题材（现实、言情、悬疑、玄幻、历史、武侠、科幻……）的小说创作方法论。
本知识库由流水线按阶段自动注入提示词，也可以脱离流水线直接当作写作参考。

## 目录

| 模块 | 内容 |
|---|---|
| `01-概论` | 讲故事的本质、类型全景与定位、主题与立意 |
| `02-世界设定` | 设定构建方法、规则体系与代价、社会质感、时代与日常细节 |
| `03-角色` | 角色构建、关系与对手、对话与语言指纹 |
| `04-情节结构` | 整体结构与节奏、章节与钩子、冲突与悬念、高潮与结局 |
| `05-文风与叙事` | 叙事视角、描写与沉浸感、语言节奏 |
| `06-素材与创意` | 灵感方法、常见套路、反套路与创新 |
| `07-参考` | 审稿自查清单、类型写作速查、修改示例与病句诊所 |
| `08-质量规则` | 文稿质量红线、镜面原则（故事照见现实） |
| `09-短篇写作` | 短篇小说工艺（`--form short` 自动注入） |
| `10-题材模块` | 言情/悬疑推理/玄幻奇幻/都市现实/历史/武侠仙侠/科幻（`--genre` 自动注入） |

## 使用方式

- 流水线：`pipeline/kb.py` 按阶段映射自动注入相关模块（多模块预算均衡，长文保头保尾）。
- 检索：`python pipeline/run.py kb <关键词>`。
- 单项目挂载：`init --kb-modules <模块目录名>` 或直接编辑 `project.json` 的 `kb_modules`。

约定：每篇文档末尾的「本篇要点速查」是给模型与作者的行动清单，截断注入时优先保留。
