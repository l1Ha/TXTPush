# 常见套路清单：知道套路才能用好套路

## 一、套路为何有效

套路是**被反复验证过的情绪装置**，它之所以存在，是因为它对应真实的读者期待。写作者的问题从来不是「用不用套路」，而是**知不知道自己在用**，以及**用完有没有给读者新的东西**。

原则：**先满足，再变化**——满足类型承诺（见 `01-概论/02`），在关键处做一次属于这本书的偏离。

## 二、通用套路

**开局**：废柴逆袭 / 天降奇遇 / 至暗时刻开局 / 平静日常被打破 / 倒叙悬念。

**关系**：欢喜冤家 / 青梅竹马 / 宿敌变盟友 / 亦师亦敌 / 双主角镜像。

**剧情**：身份错认、隐藏血脉、失忆、掉马（身份暴露）、扮猪吃虎、真假千金、复仇回环。

**结构**：先抑后扬、双线交汇、时间循环、罗生门（多视角）、反转再反转。

**结尾**：圆满团圆、牺牲成仁、真相大白、开放式、留白余味。

## 三、分类型高频套路

| 类型 | 高频套路 | 读者要的 |
|---|---|---|
| 言情 | 追妻火葬场、先婚后爱、破镜重圆、暗恋成真 | 关系的拉扯与确认 |
| 悬疑推理 | 密室、暴风雪山庄、叙述性诡计、连环案 | 公平线索与解谜快感 |
| 玄幻奇幻 | 升级打怪、师门养成、秘境夺宝、扮猪吃虎 | 成长与力量快感 |
| 都市现实 | 逆袭翻身、隐忍打脸、行业博弈、豪门恩怨 | 真实处境的代入 |
| 历史 | 权谋夺嫡、乱世枭雄、穿越改命、和亲联姻 | 时代质感 + 命运交织 |
| 武侠仙侠 | 江湖恩怨、师承复仇、正邪对决、飞升问道 | 侠义、师承与意境 |
| 科幻 | 末世求生、时间悖论、AI 觉醒、缸中之脑 | 新设定下的推演与惊奇 |

## 四、套路的正确用法

1. **给套路一个具体的外壳**：同样是「复仇」，放在哪一行、哪一种关系里，就决定它是否新鲜；
2. **让套路付出代价**：逆袭要写成「赢了但也失去了什么」；
3. **在读者以为懂的拐点做一次偏离**：他们预期 A，你给 A 的一半加 B；
4. **只保留最有效的两三个套路**，其余删掉，避免「缝合怪」。

## 五、套路失效的信号

- 主角的一切顺利都来自巧合与赠送；
- 反派为坏而坏，工具人属性明显；
- 反转只是为了爽，没有伏笔与代价；
- 桥段似曾相识到读者能预判下一句；
- 人物的选择被套路绑架，不符合他建立起的性格。

## 六、实操清单

1. 列出你打算用的套路，标出每个服务于哪一项读者期待；
2. 为每个套路补一个「具体外壳」（行业/地域/身份）；
3. 至少挑一个套路做偏离设计，写清偏离点与补偿；
4. 检查反派与配角是否沦为套路的零件，是则加动机；
5. 通读大纲，删掉会议式堆叠的多余套路。

## 本篇要点速查

- 套路是情绪装置，先满足再变化；
- 通用套路：开局 / 关系 / 剧情 / 结构 / 结尾；
- 每个类型有专属高频套路，对应各自读者期待；
- 用好套路＝具体外壳 + 付出代价 + 一次偏离；
- 失效信号：巧合开挂、反派空心、反转无伏笔。
