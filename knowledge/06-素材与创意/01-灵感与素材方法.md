# 灵感与素材方法

## 一、灵感不是等来的：五个生成器

1. **「如果」发生器**：从身边事物出发加一个假设——如果楼下那家永远不关门的打印店，其实是个接头点？
2. **新闻深挖法**：找一条真实新闻，往下追问三层「为什么把他逼到这一步」，故事就藏在地三层的细节里；
3. **身份交换法**：把两个身份悬殊的人放进同一件事（外卖骑手与公司高管在同一起事故里）；
4. **旧物考古法**：一件旧物启一段历史（一本 1999 年的账本、一张褪色的车票、一枚变形钥匙）；
5. **限制反转法**：先设一个外在限制（七天、五平米、一部不能挂断的电话），让故事在限制里生长。

## 二、素材库的建设

写作者最缺的不是才华，是**能随手取用的细节**。建三个库：

- **观察库**：随身记录具体的动作、对话、气味（公交上的两个阿姨、菜场的吆喝、医院走廊的光）；
- **知识库**：职业流程、方言词、行话、器物名称——按主题归档（医院/法院/工厂/乡镇）；
- **情绪库**：你自己的羞愧、狂喜、恐惧瞬间，写成 100 字以内的速写——它们是未来所有情感戏的燃料。

**纪律**：素材记录必须具体（「他抱怨累」无效；「他数着还剩几次化疗说，这个月车费比药费贵」有效）。

## 三、在地性：写出只有你能写的东西

你的家乡、职业、方言、家族史，是最难被抄袭的素材。方法：

- 列一张「只有我写得出」的清单（十项）：地方吃食、家族口音、老厂的规矩、方言的骂人话；
- 每项写 200 字速写，先在短篇或章节里试用；
- 用在地细节替换通用细节（「她煮了碗面」→「她下了把挂面，灶上那口锅还是结婚时带过来的」）。

## 四、从灵感到故事：三问转化法

有了灵感点之后，问三个问题把它变成故事：

1. **谁最怕这件事发生？**（找到主角）
2. **他为此会做什么、绝不肯做什么？**（找到冲突）
3. **事情解决之后，他会变成什么人？**（找到弧光）

三个问题答完，故事骨架就有了。答不出来的灵感点，先存进素材库，不要硬写。

## 五、创意的组合公式

「A + B」的组合法最快出差异化：

- 题材 A + 职业 B（悬疑 + 殡葬业）
- 结构 A + 视角 B（倒叙 + 不可靠叙述者）
- 母题 A + 地域 B（返乡 + 东北小城 / 西南山地 / 江南水乡）

组合检验三问：市场上有没有（差异化）？我能不能写（在地性）？读者为什么想看（承诺）？

## 六、常见错误

- 等「大灵感」，不写小练习；
- 素材全是抽象总结，没有可用的具体细节；
- 灵感点之间互相模仿（同一款反转写三本书）；
- 简介写得漂亮，但答不出「谁、想要什么、被什么挡住」；
- 素材只收集不消化：记了三千条，写作时一条用不上。

## 七、实操清单

1. 用五个生成器各写一个 ≤100 字的灵感点；
2. 建三个素材库文档，本周各填 10 条具体细节；
3. 列「只有我写得出」清单（≥10 项），挑一项写 200 字速写；
4. 用三问转化法把最强的一个灵感点变成故事骨架；
5. 组合三个「A+B」创意，给每个写一句 logline。

## 本篇要点速查

- 五个生成器：如果 / 新闻深挖 / 身份交换 / 旧物考古 / 限制反转；
- 三库建设：观察 / 知识 / 情绪，全部要具体；
- 在地性是护城河；
- 三问转化：谁最怕 / 他会做什么 / 他变成谁；
- 组合公式 A+B，三问检验差异化。
