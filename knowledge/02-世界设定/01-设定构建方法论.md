# 设定构建方法论（现实与架空通用）

## 一、设定只为三件事服务

世界观、时代背景、行业规则、力量体系……所有设定都只应服务于三件事：

1. **制造冲突**（资源稀缺、规则严苛、立场对立）；
2. **限制主角**（阻止他一步登天）；
3. **提供质感**（让读者相信这个世界真的在运转）。

任何不服务于这三者的设定，都是布景，写进文档供参考可以，**不要塞进正文**。

## 二、五问法：把设定问到底

对每一项核心设定，依次回答五个问题：

1. **谁在用**？——这项设定影响哪些人、哪些职业、哪些阶层？
2. **代价是什么**？——使用它要付出什么（钱、寿命、名声、关系、机会）？
3. **谁控制**？——资源与权力掌握在谁手里，门槛是什么？
4. **它坏了会怎样**？——规则失效/被滥用时，具体的失败形态是什么？
5. **它如何进入日常**？——普通人的一天里，它在哪个环节出现？

五问答不满的设定，说明它还没想透；想透的设定自然会长出情节。

## 三、冰山原则：设定做十分，写出去三分

文档里写十页，正文里可能只出现三句——但读者能从这三句里嗅到背后有九页半的存在。典型的手法：

- **术语的克制使用**：行业内行话出现 1~2 次，附带行为反应，不解释；
- **流程细节**：办事要盖哪几个章、修车要先验什么码——比形容词有说服力；
- **被省略的因果**：人物对某项规则的反应本身就是说明书（他听说要「二轮抽签」，脸色就变了）。

**反面教材**：开篇设定讲座、借角色之口科普、括号解释、页脚注释。

## 四、设定与情节的咬合：让设定做「挡路石」

好设定会主动制造情节：把某项规则往主角的欲望方向一放，冲突自然发生。

示例（同一设定的两种用法）：

- 弱用法：设定里写「城中宵禁」，正文里描写夜景很美；
- 强用法：主角必须赶在宵禁前把药送到城东，而唯一近路要穿过巡夜司的防区。

**检验方法**：删掉大纲里的核心设定，情节是否塌陷？塌陷 = 设定在干活；不塌陷 = 设定是布景。

## 五、一致性与「考古感」

- 一致性：同一规则不能在不同章节里换算法/换门槛。用编号（W1、W2……）把硬性设定固化下来，写作与审校都对照检查；
- 考古感：世界应当有「前史」的痕迹——废弃的旧制、过时的称呼、上一代人留下的习惯。它们是质感，也是伏笔的温床。

## 六、常见错误

- 设定巨细靡遗，但一条都不影响人物；
- 规则随剧情需要临场放宽（读者对「无代价开挂」极度敏感）；
- 只有建筑与制度，没有气味与工资；
- 架空世界却用纯现代口头禅与思维讲道理。

## 七、实操清单

1. 把全部设定列成表，逐条标注「服务于冲突/限制/质感」中的哪一项，悬空的删或改；
2. 对 5 项核心设定各写一遍五问法的答案；
3. 找出一处「设定当挡路石」的场景写进大纲；
4. 把硬性设定编号化（W1…Wn），并写下每条的「触犯后果」；
5. 检查前 50 页：有没有出现任何一段连续 200 字以上的设定说明？

## 本篇要点速查

- 设定三用途：制造冲突、限制主角、提供质感；
- 五问法：谁在用 / 代价 / 谁控制 / 坏了怎样 / 如何进日常；
- 冰山原则：文档做十分，正文露三分；
- 设定要当挡路石，不是背景墙；
- 硬性设定编号化，写明触犯后果。
