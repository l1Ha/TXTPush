# 规则体系与代价（幻想题材核心）

## 一、力量体系的铁律：一切能力都有价格

读者可以接受任何离谱的设定，但不能接受**没有代价的能力**。力量体系的可信度不来自数字大小，而来自三件事：

1. **限制**：能做什么，不能做什么（边界要写得比能力更清楚）；
2. **代价**：使用后失去什么（体力、寿命、记忆、人情、机会、道德底线）；
3. **成长逻辑**：变强需要什么（时间、资源、痛苦、传承），为什么别人做不到。

**自检**：如果主角的每次困境都可以用「更用力地使用能力」化解，体系就崩了。

## 二、代价的四种类型（从软到硬）

| 类型 | 例子 | 文学效果 |
|---|---|---|
| 生理代价 | 内力耗竭、血脉反噬、失眠 | 直观、好用，但用多了廉价 |
| 资源代价 | 灵石、药剂、情报、时间窗口 | 制造经济与策略层面的冲突 |
| 关系代价 | 师门决裂、身份暴露、连累他人 | 制造道德困境，主题含量最高 |
| 存在代价 | 记忆、寿数、姓名、情感能力 | 适合中后段的重锤，少用则贵 |

高手写法：一次施法同时收两种代价——一种即时的（吐血），一种延迟的（三年后寿数枯竭）。

## 三、体系的四条一致性规则

1. **规则对所有人成立**（敌人同样受限制，反派不能靠双标碾压）；
2. **等价交换可验算**（十斤铁换一把刀，十斤精铁换三把——读者会算账）；
3. **上限明确**（世上最强的人强到什么程度，要有传说与坐标）；
4. **例外要提前埋伏笔**（天选之人、禁忌术法，必须在前文出现诱因与代价，而不是决战时突然觉醒）。

## 四、势力与江湖：给冲突建基础设施

体系之外，请给世界建 3~5 个**利益集团**，每个写清：靠什么吃饭、与主角的关系、内部矛盾。

- 集团之间要有**结构性矛盾**（路线之争、资源之争、旧仇），不要只是「正邪两派」；
- 每个集团内部要有**裂缝**（一个被排挤的长老、一个出身底层的弟子）；
- 主角的行动最好能同时搅动两个集团的矛盾——这是长篇持续供能的方式。

## 五、境界/等级写法的注意事项

- 等级名要成体系（有出处、有文化逻辑），不要「一层二层」；
- 升阶要写「失去」：闭关三年失去的亲情、冲关失败落下的隐疾；
- 战斗描写由「等级差」主导会迅速无聊——用环境、情报差、代价承受到极限时的判断力来增加变数；
- 排行榜、天才谱系是天然的情节发动机，但要给「被榜单埋没的人」留位置（伏笔富矿）。

## 六、常见错误

- 开局给主角外挂，后期无代价使用；
- 数字通胀：第 10 章「千年一遇」，第 30 章「万年一遇」；
- 规则只在主角需要时被提起；
- 势力只是名字：青玄宗、黑风寨轮番出场，动机完全相同；
- 用「天赋异禀」解释一切成长。

## 七、实操清单

1. 写一页「力量总表」：能力 / 限制 / 代价 / 谁能用 / 上限；
2. 为代价准备三档强度，摊到全书节奏里；
3. 建 3~5 个势力，各写「结构矛盾 + 内部裂缝」；
4. 给体系写三条禁忌（永久性禁令，违反者全书唯一一个，且要付满代价）；
5. 检查前 100 页：主角是否经历过至少一次「付不起代价而选择放弃」？

## 本篇要点速查

- 可信度 = 限制 + 代价 + 成长逻辑；
- 代价四型：生理 / 资源 / 关系 / 存在，重锤少用；
- 体系四规则：通则一致、可验算、上限明确、例外有伏笔；
- 势力要有结构性矛盾与内部裂缝；
- 升阶写失去，战斗靠变数。
