# 现实题材的社会质感

## 一、质感从哪来：钱、流程、称呼

现实题材的可信度不靠宏大叙事，靠三样东西：

1. **钱**：人物挣多少、花多少、欠多少。写明具体数字与来源，故事立刻落地；
2. **流程**：办事的真实顺序——挂号、报案、过户、报销、退货。流程本身就是情节与冲突（谁卡在哪一环）；
3. **称呼**：不同场合对同一人的称呼不同（主任/老张/张姐/小张）——称呼的切换记录着关系的亲疏与权力的位置。

**底线**：写你不了解的职业，至少找到一位行内人的经历叙述（回忆录、访谈、报道均可），把流程写到「能骗过同行」的一半即可。

## 二、阶层与处境：不要平均化所有人

现实世界里的人被四种东西分层：**收入、地域、教育、家庭网络**。人物的选择空间由这四者决定：

- 月薪五千的人不会「顺手」买下三千的礼物；
- 家里有病人的人，对加班与失业的恐惧与他人不同；
- 小城的「体面」与大城市的不同——面子货币不一样。

写作时始终问：**这个人物能做什么、不能做什么？为什么？** 答案就是情节与冲突的来源。

## 三、机构与权力：具体的对手比宏大的敌人可怕

现实题材的压迫感往往来自「系统里的具体环节」：

- 一个按章办事的窗口、一句「材料不齐」、一个不敢签字的科长；
- 一纸通知、一次公示、一场评估、一个 KPI。

写这些时避免漫画化：办事员也有他的难处与考核。**让制度冷冰冰地运转，比让坏人张牙舞爪更真实，也更有压迫感。**

## 四、行业写作三件套

写职业/行业题材（医生、律师、老师、小店主、快递站、乡镇干部、程序员……）：

1. **专业动作**：写得出手上在做什么（不玄乎，但准确）；
2. **行话浓度**：全书 10~20 处，附带反应，不解释；
3. **职业困境**：每个行业都有自己的两难（救谁、告不告、接不接这单），把主角放进去。

## 五、城市与乡土：空间的性格

- 大城：效率、匿名、通勤、租金——孤独感来自人群；
- 小城/乡镇：熟人社会、关系网、面子——压力来自被所有人看见；
- 乡村：土地、宗族、季节——命运的刻度是天时与土地。

选择空间就是选择冲突类型。**不要写「某城市」，要写出只有这个城市才有的东西。**

## 六、常见错误

- 悬浮职场：全员住大平层、上班只为谈恋爱；
- 穷人写不出穷的细节，富人写不出富的边界；
- 反派是抽象资本/抽象体制，没有一张具体的脸；
- 新闻腔（报道语体）代替人物视角；
- 「网络热词」硬塞中年角色之口。

## 七、实操清单

1. 给主要人物写一张「经济卡」：月收入 / 固定支出 / 存款 / 债务；
2. 挑一场戏，把流程写实（谁先开口、要带什么、盖几个章）；
3. 统计全文的称呼变化：关系冷暖看称呼；
4. 写出主角行业的一个具体两难，放进中段剧情；
5. 删掉所有「报道式」段落，改写成人物的可见所见。

## 本篇要点速查

- 三件套：钱 / 流程 / 称呼；
- 处境四分层：收入、地域、教育、家庭网络；
- 制度比坏人可怕：写具体环节，不漫画化；
- 行业写作：动作准确、行话克制、职业两难；
- 空间有性格，空间决定冲突类型。
