# 玄幻奇幻写作要点

## 一、核心承诺：成长快感 + 世界奇观

读者要两样东西：**看着主角一步步变强**，以及**进入一个前所未见的世界**。两者缺一，都会变成「设定展览」或「无脑升级」。

## 二、力量体系：一切能力都有价格

- **限制**：能做什么、不能做什么，边界要比能力写得更清楚；
- **代价**：使用后失去什么（体力、寿数、记忆、人情、道德底线）；
- **成长逻辑**：变强需要什么（时间、资源、痛苦、传承），为什么别人做不到。

**自检**：如果主角每次困境都能靠「更用力地使用能力」化解，体系就崩了。

## 三、等级与成长：写「失去」，不只写「得到」

- 等级名要有体系与出处（文化逻辑），不要「一层二层」；
- 升阶要写代价：闭关三年失去的亲情、冲关失败落下的隐疾；
- 战斗由「等级差」主导会迅速无聊——用环境、情报差、代价承受极限时的判断力增加变数；
- 排行榜、天才谱系是天然的情节发动机，但要给「被榜单埋没的人」留位置（伏笔富矿）。

## 四、世界奇观：用得上，才写得出

- 每项奇观（浮空城、灵脉、异兽）都要能**制造冲突、限制主角或提供质感**，否则是布景；
- 用**五问法**推演：谁在用 / 代价 / 谁控制 / 坏了怎样 / 如何进入日常；
- 术语克制使用（1~2 次并附行为反应），不解释。

## 五、势力与江湖：冲突的基础设施

- 建 3~5 个利益集团，各写「靠什么吃饭 / 与主角关系 / 内部裂缝」；
- 集团之间要有**结构性矛盾**（路线、资源、旧仇），不要只有正邪两派；
- 主角行动最好同时搅动两个集团——这是长篇持续供能的方式。

## 六、常见错误

- 开局送外挂，后期无代价使用；
- 数字通胀（第 10 章「千年一遇」，第 30 章「万年一遇」）；
- 规则只在主角需要时被提起；
- 势力只是名字，动机完全相同；
- 只有打斗，没有世界与人情。

## 七、实操清单

1. 写一页「力量总表」：能力 / 限制 / 代价 / 谁能用 / 上限；
2. 为代价准备三档强度，摊到全书节奏里；
3. 建 3~5 个势力，各写「结构矛盾 + 内部裂缝」；
4. 给体系写三条永久禁忌，违反者需付满代价；
5. 检查前 100 页：主角是否经历过至少一次「付不起代价而放弃」？

## 本篇要点速查

- 核心＝成长快感 + 世界奇观，二者不可缺；
- 可信度 = 限制 + 代价 + 成长逻辑；
- 升阶写失去，战斗靠变数；
- 势力要有结构性矛盾与内部裂缝；
- 奇观要服务冲突/限制/质感，术语克制。
